# Durability baseline: windows-dev

Dataset: SNAP soc-Pokec, 30,622,564 directed edges (https://snap.stanford.edu/data/soc-pokec-relationships.txt.gz).
Machine: see bench/baseline/MACHINE.md (AMD Ryzen 7 5700U, Windows 11, 7.3 GB RAM).
Heap: -Xmx6g for every phase. Each phase runs in its own JVM.

Commands, in order:

    java -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark prepare <work> soc-pokec-relationships.txt.gz
    java -Xmx6g -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark memory <work>
    java -Xmx6g -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark durable-async <work>
    java -Xmx6g -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark recover <work>
    java -Xmx6g -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark durable-sync-batch <work>
    java -Xmx6g -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark recover <work> durable-sync-batch
    java -Xmx6g -cp bench/benchmarks.jar io.nodusdb.kernel.wal.DurabilityBenchmark single-call <work>

Digests are FNV-style hashes of every node's out-degree and in-degree, plus the sorted 3-hop reach of 300
sampled start nodes. The recovered digests must match the pre-crash digests.
